Good to know

01How it works

Unicode has Cyrillic letters drawn with exactly the same shape as Latin ones. а and a look alike but have different code points, so any text field treats them as different characters.

With n swappable letters there are 2n − 1 variations. Namify lists them from the subtlest (one swap) to the heaviest.

02Where it works

Anywhere a display name accepts Unicode: most games, chat apps and social profiles.

It will not work in ASCII-only fields such as email addresses or many login usernames, and people searching the Latin spelling won't find the lookalike.

03Caveats

A few fonts draw some letters slightly differently. Use the font preview and the U+ button on any row to double-check.

Some platforms flag mixed-script names. Use this for your own handle, not to pass yourself off as someone else — that's against nearly every platform's rules.
